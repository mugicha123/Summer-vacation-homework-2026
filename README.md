# Summer-vacation-homework-2026
icon.pngはGoogle FontsのVpn Lock 2を使用しています。<br>
このv1.0はSPA(Single Page Application)の対策をしていません。<br>
つまりyoutubeなどのサイトは完全にロックすることはできません。

## 解除方法
解除方法はctrl+shift+jを押してconsoleタグを開きます。<br>
そして上のバーにtopと書かれているのをクリックします。<br>
lockPageと書かれた項目をクリックします。<br>
そしてcancellation()と入力します。<br>
するとパスワードが聞かれるます。<br>
初期設定で0123と表示されています。
